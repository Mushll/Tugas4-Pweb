# Membuat Front-end CSS Form
Laporan tugas mata kuliah Pemrograman Web: membuat tampilan Student Management (Data Mahasiswa) menggunakan HTML & CSS

# Tujuan
1. Membuat struktur halaman dengan HTML semantik.
2. Menerapkan CSS modern: Variables, Flexbox, Grid, Box Model, pseudo-class, dan Media Query.
3. Membangun komponen UI yang dapat dipakai ulang (card, form, button, table, pagination).
4. Menambahkan interaksi dasar dengan JavaScript (tambah, ubah, hapus, cari data).
